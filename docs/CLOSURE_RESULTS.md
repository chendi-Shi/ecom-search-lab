# 从消融到可验证的修正：Closure v1

本次已完成独立查询队列上的训练、验证集选型、一次最终测试和服务发布决策。验证集选择 **`soft_bm25`**；最终门槛通过，服务采用 **`soft_bm25`**。

完成流程并不自动意味着准确率提高；下表保留最终实际结果，不能把验证集收益当作测试集结论。

## 新数据与一次性测试

使用 46,249 件商品，800 / 200 / 300 个 train / validation / test query。最终 test 含 11,306 个原始人工判断对。新队列与此前3305个query的官方ID及归一化文本交集均为零；商品和语义改写不保证互斥，预训练语料也不在此排除证明内。[数据协议](CLOSURE_DATA.md)。

每个 query 的已知正例为 E/S（grade≥2）。无已知正例的 query 有 0 个，其 Recall 未定义且不进入Recall均值；仍保留在总体与缺失计数。这是有限人工判断商品并集上的已知正例召回，未标注商品保持未知，不能视为负例。judged@10 是判断覆盖率，不是相关性Precision。

## 验证集：固定六个配置

每个配置均使用自己的召回池，pool=100。验证规则先要求候选Recall@100不低于基线均值，再按Recall@10取最高；相同分数按固定顺序、基线优先。

| 配置 | 已知正例Recall@10 | 候选Recall@100 | judged@10 | 候选覆盖约束 |
|---|---:|---:|---:|---|
| 旧硬过滤 + BM25 (`legacy_bm25`) | 19.127% | 59.159% | 64.050% | 满足 |
| 旧硬过滤 + 人工候选训练 (`legacy_judged`) | 18.189% | 59.159% | 61.450% | 满足 |
| 旧硬过滤 + 召回交集训练 (`legacy_retrieved`) | 18.665% | 59.159% | 63.150% | 满足 |
| 取消自然语言硬过滤 + BM25 (`soft_bm25`) | 19.828% | 63.734% | 67.050% | 满足 |
| 取消自然语言硬过滤 + 人工候选训练 (`soft_judged`) | 18.503% | 63.734% | 62.450% | 满足 |
| 取消自然语言硬过滤 + 召回交集训练 (`soft_retrieved`) | 18.909% | 63.734% | 63.900% | 满足 |

验证集内的模块差值如下，单位为百分点。它们参与选型，属于探索性解释，没有独立测试确认，也不计算或宣称可相加的贡献比例。

| 对照（后−前） | ΔRecall@10 | Δ候选Recall@100 | Δjudged@10 |
|---|---:|---:|---:|
| 取消自然语言硬过滤，固定bm25 | +0.701 | +4.575 | +3.000 |
| 取消自然语言硬过滤，固定judged | +0.314 | +4.575 | +1.000 |
| 取消自然语言硬过滤，固定retrieved | +0.244 | +4.575 | +0.750 |
| 人工候选训练→召回交集训练，固定legacy | +0.476 | +0.000 | +1.700 |
| 人工候选训练→召回交集训练，固定soft | +0.406 | +0.000 | +1.450 |

`soft` 取消自然语言否定的硬过滤，只有显式 `-word` 保留字面硬过滤；学习排序器仍可使用否定特征。`soft_bm25` 只使用BM25排序，不使用否定排序特征。这些配置都不是语义约束保证。`retrieved` 只使用 soft top100 与已有人工qrels的交集训练；未标注召回商品不充当负例。改变训练池也会改变可用训练对数量，因此不能将其效果解释为单一特征的因果贡献。

## 最终测试：只比较冻结赢家与基线

| 方法 | 已知正例Recall@10 | 候选Recall@100 | judged@10 |
|---|---:|---:|---:|
| `legacy_bm25` | 20.348% | 62.166% | 64.067% |
| `soft_bm25` | 20.785% | 66.930% | 66.333% |

| 冻结赢家−基线 | 差值（百分点） | 配对95%区间（百分点） |
|---|---:|---:|
| 主要指标 Recall@10 | +0.437 | [+0.060, +0.897] |
| 候选覆盖 Recall@100 | +4.763 | [+3.150, +6.601] |

区间为 query 级配对 percentile bootstrap，2000次、seed=20261013。最终仅有一个事先冻结的主要比较，候选覆盖是联合发布约束。区间反映查询抽样不确定性，不覆盖训练随机种子、其他商品库或线上流量变化。

发布门槛是：主要指标Δ的95%下界严格大于0；同时候选Recall@100的Δ下界至少−1个百分点。选择基线本身也不会被记成新方法晋级。

实际决定：**晋级**；服务配置 `soft_bm25`。原因码：`none`。服务读取冻结release并复核指纹；未通过门槛的实验模型仍留在报告，不作为默认服务。

## 训练范围和成本

| 训练候选来源 | 可形成偏好对的query | 采样偏好对数 | 初始→最终loss | 拟合耗时（秒） |
|---|---:|---:|---:|---:|
| judged | 800 | 78,910 | 0.676078→0.641827 | 214.31 |
| retrieved | 730 | 58,689 | 0.690635→0.648241 | 141.68 |

训练召回共 73,735 个商品位置，其中 18,879 已判断、54,856 未判断并忽略；70 个query无法形成训练对，26 个没有已判断召回商品。总训练阶段耗时 804.22 秒。耗时是单CPU进程在未控制主机负载下的诊断值，不是生产容量或延迟承诺。
