# 完整 CPU 版本：实际结果与边界

版本 v0.2 将 JD 的排序、多模态、用户偏好、生成式检索和资源利用落到可运行代码、真实数据实验和本地页面。不同任务保留独立商品池；不把缺失图片或用户历史补造成 ESCI 标签。页面服务是本机单进程实验，不能代表生产系统吞吐。

| 已完成能力 | 实际数据与训练 | 可核对的结果 |
|---|---|---|
| 文本学习排序 | ESCI 250/50/100 Query；同 Query pairwise logistic；12 个特征 | 固定 20 候选 NDCG@10：0.7315 → 0.7606；39 条长 Query：0.7234 → 0.7701 |
| 复杂 Query | 英文排除、品牌、短语、数字、字符匹配；共享约束过滤 | Nike 排除与 sugar-free 保留在 API 验证；无人工意图理解金标 |
| 多模态 | 200 个 dresses 商品、400 张真实照片；商品分离 120/40/40；冻结 TinyCLIP，训练 1,025 参数 | 40 测试商品跨视图 Pair Recall@10：纯图片 82.5% → 学习图文融合 90%；R@1：60% → 67.5% |
| 真实历史推荐 | Luxury Beauty 29,059 去重真实评分事件；全局时间切分；16 维 BPR | 1,000 测试事件 NDCG@10：0.154594 → 0.159668；Recall@10：0.263 → 0.254；用户簇 bootstrap 两项区间跨 0 |
| 显式搜索偏好 | 本机 SQLite 收藏、隐藏、历史；候选相关性与偏好相似度融合 | 冷用户保持相关性排序；显式隐藏从结果过滤；不是 Beauty 离线推荐收益 |
| ANN | 同一 MiniLM 向量 Flat 与 HNSW，验证选 ef=64 | Neighbor Recall@10=99%；已缓存向量检索 p95 70.7 ms → 1.46 ms；图索引更大 |
| 生成式检索 | 250/50/100 ESCI Query；162,728 参数条件 GRU；验证选 60 epochs、beam=10 | 已知 E/S Recall@10/@100：0.01942/0.08886，明显弱于 BM25 的 0.22267/0.66898 与 Flat 的 0.21972/0.72592 |
| 分块 int8 存储 | 15,171 × 384 本地 mmap；块内 top-k，最多保留 k 个赢家 | float32 23,606,209 bytes → int8 6,190,029 bytes；Neighbor Recall@10=99.8%；已知 E/S Recall@100 相同 0.725922 |

上述相似近邻 Recall 与 E/S 已知正例 Recall 是不同指标。int8 本次 p95 为 47.59 ms，float32 为 35.00 ms，均排除文本编码；节省存储并未带来更低延迟。显式数组工作区估算不等于整个 Python 进程 RSS，OS 页缓存和编码器内存另计。

多模态测试只含 40 个 dresses 商品，使用同商品的不同视图配对代理标签。文字来源未说明标注方法；数据与模型预训练的重叠未知。不能将 90% 写作购物搜索满意度或线上提升。

BPR 的 95% 用户簇 bootstrap 区间：NDCG 差值 [-0.007311, 0.016291]；Recall 差值 [-0.027888, 0.009009]。288 个冷用户测试事件回退热门。必须同时报告两项指标，不宣称显著提升。

生成式检索的完整冻结实验结果保留在 `outputs/generative-v1/report.json` 与 `report.md`，其模型为 Query 向量条件 GRU，自回归生成 4 层 × 8 类 Semantic ID。仅 train E/S 商品拟合码本；合法 prefix trie 约束 beam；碰撞只在对应 bucket 内 cosine 消歧。新增解码器 162,728 参数，仍保留 23 MB 商品向量，不能称为无索引或存储已消除。

训练加验证 414.55 秒；测试非法 ID 为 0。3,065 个语义 ID 覆盖目录，94.67% 商品处于碰撞 bucket，最大 bucket 115。少量训练 Query 与大量同码商品是该实验的明确限制。页面默认关闭生成式召回，可主动切换研究；它没有替换默认的倒排与 int8 向量召回，也没有端到端收益证据。

所有参数按各自验证集选择后才评估测试集。收藏偏好是用户明确输入的本地信号；实验用户来自独立公开研究数据。页面图片商品属于 Fashion200K，历史推荐属于 Luxury Beauty，不与 ESCI ASIN 拼接。

项目文件包括模型/输入 SHA、split 检查、训练协议、真实差例与资源报告。`scripts/verify.py` 检查契约，`scripts/api_smoke_full.py` 验证完整服务。首次端到端编码与已缓存向量测时口径分开，不把检索计算毫秒数说成首次请求耗时。

可用于简历的准确表述：基于 Amazon ESCI 扩展 CPU 电商搜索实验，实现学习排序与复杂 Query 约束；在真实服饰图文配对数据上训练轻量融合模块；实现 Query 条件自回归 Semantic ID 检索与真实时间切分 BPR 推荐；对比 HNSW、分块 int8 存储的质量、延迟和空间取舍。具体量化数字须保留对应数据与评测范围。
